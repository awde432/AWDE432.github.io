## 这是什么

ViMoxPC 是一款面向 64 位 Windows 的远程控制工具，支持远程协助、教学演示与设备管理场景。
连接需通过口令校验，且必须由被控端本人点击「允许」确认授权后才会建立会话。

- 最新版本：**v1.1.0**
- 下载页：https://github.com/awde432/AWDE432.github.io/releases/tag/v1.1.0
